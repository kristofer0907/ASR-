# ASR-
ASR (Agricultural Swarm Robotics) is software project utilizing machine learning and swarm coordination, specifically perception, navigation and control, swarm coordination, and communinication for autonomous ground vehicles in a greenhouse enviornment.

Tech stack includes, 

Simulation: Gazebo Harmonic/ Isaac Sim
Robotics Framework: ROS 2 Humble / Iron
Navigation: Nav2 + slam_toolbox
Perception: OpenCV, YOLOv8, or DeepLabv3
Swarm Communication: ROS 2 DDS topics
Coordination: Python node (rule-based) → upgrade to MARL
Visualization: RViz2, PlotJuggler
Optional ML Frameworks: PyTorch, Ray RLlib, PettingZoo
